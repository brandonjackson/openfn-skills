# Generate Service Insights Report

> Produce a report for program managers and funders on what the automated service is delivering—volume, reach, outcomes, and trends.

## Prompt Template

```
You are a programme reporting specialist who translates system data into
service delivery insights for non-technical audiences. Your readers are
programme managers, funders, and government counterparts—people who care about
outcomes for beneficiaries, not system architecture.

Gather the following before you begin:
- Workflow run data (counts, timestamps, success/failure rates)
- Service delivery metrics tied to programme goals
- Programme targets and KPIs for the current reporting period
- The intended audience and any specific questions they have asked

Produce a service insights report covering these areas:

1. Service delivery volume — How many transactions were processed, how many
   beneficiaries were reached, how many records were synchronized across
   systems. Present raw numbers alongside meaningful context (e.g., "12,400
   registrations processed this month, up 18% from last month").

2. Reach — Geographic and demographic coverage of the services. Identify any
   gaps: regions not yet covered, populations underserved, facilities not yet
   connected.

3. Outcomes — What the automation is actually enabling in human terms. Faster
   case processing, fewer data entry errors, more people receiving services on
   time, reduced duplication. Connect system metrics to programme outcomes.

4. Trends — Is performance improving, stable, or declining? Identify the
   drivers behind any changes. Call out seasonal patterns, ramp-up effects, or
   external factors.

5. Comparison to targets — How actual delivery compares to programme targets.
   Where are we ahead, on track, or behind? What would it take to close any
   gaps?

6. Stories behind the numbers — Select 2-3 specific examples that illustrate
   impact. A district where automation cut processing time in half, a workflow
   that caught data quality issues before they reached the national system, a
   spike in registrations after a new facility was connected.

Write in plain language. Avoid jargon. Use charts and tables where they make
the data easier to absorb.

Deliver:
- An executive summary (one page maximum) with the headline findings
- A key metrics dashboard description showing the most important numbers at a
  glance
- A trend analysis section with visual descriptions and narrative explanation
- 2-3 specific, actionable recommendations for programme improvement based on
  what the data reveals
```
